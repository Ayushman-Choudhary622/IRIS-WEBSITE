The Bridge.
•  
Receives wireless stream from XIAO ESP32C3 (BLE 5.0 + Wi-Fi failover).
•  
Renders a live digital twin of the user's eye blinking in real time.
•  
Maps gestures to OS cursor actions across Windows, macOS & Android.
PYSERIAL
PYAUTOGUI
XIAO BLE / WI-FI
SIGNAL PATH
Why Python barely changes between USB and Bluetooth.
•  
XIAO TX → BLE 5.0 / Wi-Fi Failover → Python TensorFlow denoiser.
•  
Updates live eye simulation & executes PyAutoGUI cursor movement.
•  
Includes wired USB-C fallback for zero-drop hospital reliability.
import serial, pyautogui, tensorflow as tf
from iris_sim import EyeDigitalTwin

link = EyeDigitalTwin.connect(ble='IRIS_XIAO', wifi_backup=True)
eye_ui = EyeDigitalTwin.launch_live_eye_window()

while True:
    pkt = link.read_denoised_ir_imu()  # TensorFlow filter
    eye_ui.sync_blink_and_gaze(pkt.ir_beams)
    c = pkt.command
    if c == 'L':  pyautogui.moveRel(-30, 0)
    if c == 'R':  pyautogui.moveRel(30, 0)
    if c == 'U':  pyautogui.moveRel(0, -30)
    if c == 'D':  pyautogui.moveRel(0, 30)
    if c == 'LC': pyautogui.click()
    if c == 'RC': pyautogui.rightClick()

CONCEPT / THEORY
Two signals, one reliable cursor.
Optical reads your blink. Inertial reads your head. Together, they never fail.
OPTICAL  ·  IR BLINK SENSING
Sclera reflects, eyelid blocks.
•  
Projects multi-directional 950nm IR beams at the eye.
•  
Open sclera reflects strongly; closed eyelid blocks light.
•  
Python/TensorFlow filters noise & mirrors blinks live.
•  
Timing windows separate reflex blinks from clicks.
950nm
 IR · reflective sensing
INERTIAL  ·  HEAD GESTURE SENSING
Tilt your head, move the cursor.
•  
MPU6050 6-DOF MEMS reads head pitch and roll at 50Hz.
•  
Nod up/down and tilt left/right steer the cursor smoothly.
•  
Avoids the eye strain of camera-only gaze steering.
•  
Long-blink clutch re-zeros gyro to prevent drift.
MPU6050 · 6-DOF MEMS
