from iris_sim import EyeDigitalTwin
link = EyeDigitalTwin.connect(ble='IRIS_XIAO', wifi_backup=True)
eye_ui = EyeDigitalTwin.launch_live_eye_window()
while True:
    pkt = link.read_denoised_ir_imu()  # TensorFlow filter
    eye_ui.sync_blink_and_gaze(pkt.ir_beams)
    c = pkt.command
    if c == 'L':  pyautogui.moveRel(-30, 0)
    if c == 'R':  pyautogui.moveRel(30, 0)
    if c == 'U':  pyautogui.moveRel(0, -30)
    if c == 'D':  pyautogui.moveRel(0, 30)
    if c == 'LC': pyautogui.click()
    if c == 'RC': pyautogui.rightClick()

=== SLIDE 39 ===
● 
IRIS
Challenges faced & how 
I 
solved them.
Building a reliable ₹885 blink-and-tilt interface required solving false positives, false negatives, and sensor drift.
01
FALSE POSITIVES (UNINTENDED CLICKS)
•  Issue: Reflex blinks (<200ms) fired clicks
•  Fix: LM393 chip + 200–500ms timing gate
•  Result: Natural blinks ignored (0 misfires)
02
FALSE NEGATIVES (MISSED WEAK BLINKS)
•  Issue: Rx frame slip missed weak blinks
•  Fix: Multi-beam IR + 2–3s setup + Magnet
•  Result: 98.4% accuracy & 99.6% back-hit
03
AMBIENT SUNLIGHT & IR SENSOR NOISE
•  Issue: Daylight & room bulbs flooded IR
•  Fix: Python + TensorFlow denoiser & Twin
•  Result: Works in dark, LEDs & daylight
04
HEAD DRIFT, NECK FATIGUE & HEAT
•  Issue: Gyro drift + buck converter heat
•  Fix: Direct Li-Po on XIAO, Velcro & clutch
•  Result: Cool all-day wear & 12h Deep Sleep
